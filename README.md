# PrefDiag-Bench

Official repository for **Diagnosing Personalization Failures in Mobile GUI Agents**.

PrefDiag-Bench evaluates how mobile GUI agents apply user preferences during task execution. It pairs end-to-end GUI tasks with stage-wise diagnostic probes and supports two forms of user context: explicit user profiles and behavioral memory logs.

The benchmark covers five preference types: **Outcome, Constraint, Ranking, Process, and Interaction**.
